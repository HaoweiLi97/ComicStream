# CSTR 独立封面区段建议

CSTR v1 的可选封面扩展 为每本漫画提供一张可选的书架封面。打包时从原图单独生成，封面与每页缩略图可以分别启用。字段布局以 [CSTR v1 规范](../CSTR-v1.zh-CN.md) 为准。

## 生成规格

| 项目 | 建议值 |
| --- | --- |
| 来源 | 优先使用打包时指定的封面图，其次使用指定页，默认使用第一页原图 |
| 自定义封面原图 | 建议打包器接受最大 32 MiB、最多 3200 万像素的单张图片，在完整解码前检查两项限制 |
| 默认输出（推荐中档） | 640 × 909 px 边界框，编码预算 128 KiB。先校正方向，再等比缩小，小图保留原尺寸 |
| 编码 | 单帧 WebP，默认质量 85 |
| 内嵌封面硬上限 | 每本最多一张，长边最多 2560 px，编码后最多 2 MiB。打包器与阅读器均按此校验 |

用户可以直接上传扫描原图，由打包器生成中档封面。例如，一张 4000 × 6000、18 MiB 的竖版原图符合输入限制，默认生成的封面最大为 606 × 909 px。需要更清晰的详情页封面时，可以自定义为 1200 × 1800、最多 1 MiB。目标宽高和目标体积可独立调整，未指定的选项沿用中档默认值。各项均须为正整数，超出内嵌封面硬上限时提示允许的范围。

目标宽高是边界框。使用默认设置时，1200 × 1800 的原图按比例缩至 606 × 909，400 × 600 的原图保留原尺寸。目标体积是编码后的字节预算：若设置为 96 KiB，首次编码只有 70 KiB 就直接保存；若超过 96 KiB，保持所选质量，逐步等比缩小并重新编码，直到满足预算。若最小尺寸仍无法满足，报告目标过小。文件头记录最终图像的实际宽高和字节数。

## 独立写入与读取

文件头扩展记录封面的绝对字节偏移、编码后长度、宽和高。页表从文件偏移 48 开始。封面图紧接索引和可选元数据，正文紧接封面图。标志位 bit 1 为零表示没有内嵌封面。已有页面数、正文块数和逐页缩略图数均不计入封面。

书架从开头读取 64 KiB；若其中已包含完整封面，可直接显示，否则只补读封面剩余字节，无需读取页表、缩略图表或第一页正文。解码前校验文件边界、字节数和图像尺寸。封面缺失或损坏时，书架可回退到第一页预览，正文阅读仍可继续。

## 版本兼容

版本号保持为 1。封面标志未置位时继续使用原布局。带封面的文件需要支持 bit 1 的阅读器。
